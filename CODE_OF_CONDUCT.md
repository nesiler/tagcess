# Code of conduct

tagcess follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
By taking part in this project (issues, pull requests, discussions, reviews) you agree to follow it.

## Reporting
Report unacceptable behaviour to the maintainers privately, through a
[GitHub security advisory](https://github.com/nesiler/tagcess/security/advisories/new) or by contacting a maintainer
directly on GitHub. Reports are handled confidentially. The maintainers enforce the code of conduct as described
in the Contributor Covenant's enforcement guidelines.
